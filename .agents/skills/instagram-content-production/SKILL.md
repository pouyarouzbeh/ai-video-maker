# Instagram content production

Use the requested format and scope first. Normalize the input into the brief and record whether each supplied file is source media or a visual reference. For a complete or resumable project, use [production files](references/production-files.md). For export and mobile review, use [format guidance](references/formats.md). Use `instagram-portfolio-reel` for website showcases and `instagram-educational-content` for educational and scientific content.

## Start from the material

- **Photos or clips** — inspect framing and usable detail, then assign an asset to each visual beat. Preserve faces, products and logos in supplied source media. Use a reference to guide a specific property such as framing, palette, pose, or lighting.
- **Script or scenario** — preserve its intended order, narrative and exact required lines. Break it into items with clear visual action and time moving items to measured speech when available.
- **Copy or idea** — turn the goal into one message for the selected audience and build a sequence around it. Keep user-supplied facts and promises distinguishable from draft copy. Route material scientific claims through evidence review.
- **Mixed or multiple placements** — build one message and visual direction, then adapt framing, pacing, typography and calls to action for each requested placement.

## Production and revision

Use [direction and editing](references/direction-and-editing.md) for visual direction, scratch-narration animatics, editorial review and weekly reference study. The primary agent alone writes the shared storyboard. Writers and storyboard reviewers return proposed copy, sequence and continuity by item ID.

1. The primary agent turns the request into a brief. The storyboard agent can propose a sequence, and asset collection and evidence review supply the source material. For a quick or planning-only request, use only the handoffs needed to deliver the requested work.
2. For sequences, plan continuity before expensive production. Give each item a stable ID and a reference purpose. For moving shots, decide what the viewer sees at the start and end, and track screen direction, framing, subject identity and lighting when they affect the cut. Review representative stills or an animatic before heavy rendering.
3. The visual and audio agents work from the agreed sequence. Use Remotion for frame-timed edits or still compositions, Blender when a 3D camera or object is warranted, and FFmpeg for media assembly and technical checks. For image generation, use the available image-generation skill when appropriate. Save intermediate artifacts by item ID to resume work.
4. On revision, reopen the current files and regenerate the affected item and its dependents. Preserve locked copy and visuals, and check adjacent transitions, caption cues and export crops when timing or framing changes.
5. Review the requested output at phone size and deliver the export, accompanying copy or cover as applicable, and editable sources. Keep publication manual.
